# 宿主沙盒外读取 A/B 探针（本地候选）

## 基线与当前证据

- 基线为已交付的 `ff1f00fffdeee9d167253eb128134dcc33a2dca8`。
- 用户已在设备上确认普通 Minis 与 Minis Files 的数据隔离。本记录是用户反馈，不冒充本代理真机测试。
- 独立工作树 `/root/staging/openminis-20261120/host-permission-probe`；原交付树、IPA、权限配置保持不变。
- 已复查当前设置页、打包及 iSH 路径转换，没有现成的安全宿主测试入口。

## 本关要证明什么

假设：当前沙盒外 entitlement 组合能让 Minis Files 的原生进程读取**一个固定的非敏感测试文件**，而普通 Minis 被系统拒绝。不能由此外推 root、所有 App 容器、TCC 或系统卷可写。

顺序：原生本 App 读取正对照 → 固定沙盒外文件只读 A/B → 若通过，再另立可回滚的写入试验。当前阶段不增加写入能力。

## 最小实现与安全边界

- 同一 DEBUG 诊断页面可用于两种构建，入口在“设置 → 关于”；只有点击才执行，没有自动触发或 AI/Shell/MCP 工具入口。
- 显示真实原生 UID/EUID、Bundle ID、OS、固定测试路径；没有任意路径输入、目录遍历、全盘挂载、root helper、网络或外部文件写入。
- 原生 POSIX 读取核心只认 `/private/var/mobile/Media/OpenMinisPermissionProbe/sample-v1.txt`。测试内容是公开标记+非秘密 UUID，不打印文件正文。
- 本 App 正对照读取自身 Info.plist（有界读取，不输出正文），证明读取通道工作。失败时整个实验不能判通过。
- 以目录 FD 锚定测试目录，`openat`+`O_NOFOLLOW` 拒绝符号链接；拒绝 FIFO/设备/目录等非普通文件、错误标记、超限、并发变化。报告实际 errno 和失败阶段，`ENOENT`不当作权限拒绝，`EACCES`/`EPERM`不当作文件不存在。
- 记录公开样本 UUID、inode/device/mtime/size，让同机两份报告可对应同一试次。失败不会读取/回显其他文件内容。
- 样本由用户在**设备原生终端/文件管理器**准备，仅本地生成说明与脚本，不在 iSH 假造宿主样本，不自动连接/写设备。

## 验证与独立失败信号

- C 生产读取核心可在本机 clang/Linux 临时目录实际执行，覆盖成功、缺失、软链接、FIFO、超限、错误标记、目录替代、权限拒绝及目录 FD 防替换。Linux 结果不等于 iOS 沙盒/TCC 结果。
- SwiftUI 与头文件/工程注册：静态检查与语法差异检查；本机没有 Swift/Xcode，不能声称编译通过。云编译和设备安装均不在本地阶段自动进行。
- 若正对照失败、标记不符、目标缺失或两份样本 UUID 不对应，A/B 无效。
- 普通版拒绝且实验版读回匹配标记：只证明该固定路径的读取差异。两份都可读：对照未区分，不能判沙盒外组合有效。两份都拒绝：组合不足或环境限制，保存阶段/errno后再分析。

## 退出/回滚

所有源代码仅在独立工作树；既有两份IPA与修复分支不改。本关不创建commit、不push、不装机、不改权限、不扫描私人文件。
