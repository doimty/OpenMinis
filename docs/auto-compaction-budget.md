# 自动压缩及软预算（本地候选）

## 入口和使用

- 设置 → Agent Runtime → 自动压缩。
- 聊天右上角“…” → 自动压缩。原生SwiftUI和UIKit菜单都有入口。
- 开关沿用旧 `autoCompactOnThreshold` 偏好；默认关闭，已保存的用户选择保留。
- 预算默认256,000 token；预设128,000/256,000/512,000；可自定义32,000至4,000,000整数；0表示跟随模型／模型组窗口。
- 自定义值只有点击“应用”才保存，取消不改变；已有自定义值可直接再次编辑。
- 开启后，小于实际模型／组窗口的预算按85%触发压缩、70%触发工具内容卸载、55%为卸载目标。256,000预算对应217,600压缩触发线。
- 模型／组较低的实际窗口始终优先。此处是软目标，不提高模型真实窗口，也不修改provider输出token窗口分配。固定提示词、当前回合、压缩失败等可能使请求仍超过软目标。
- 关闭自动模式不关闭原有接近实际窗口上限的工具循环安全保护。原始聊天历史保留，出站摘要可能丢细节。

## 配置接口（安装新构建后才存在）

`chat.autoCompact`（bool）、`chat.autoCompactBudgetTokens`（0或32000...4000000整数）。非法CLI写入拒绝；读取损坏类型/String/Bool/非整数时回到默认预算，不误当作0。
